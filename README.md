# Maria — Birthday Dinner invitation

## Files
- `index.html` — responsive invitation website
- `maria-photo.jpg` — portrait used as the hero background

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload both files (`index.html` and `maria-photo.jpg`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the public URL it gives you.

The invitation includes a Google Calendar link, Instagram link, and Google Maps search link.
